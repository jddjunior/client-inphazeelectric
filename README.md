# In Phaze Electric

Website for In Phaze Electric services.

## Getting Started

### Prerequisites

- Node.js 16+
- npm

### Development

```bash
npm install
npm run dev
```

The site will be available at `http://localhost:3000`.

### Build

```bash
npm install
npm run build
```

This generates a static `dist/` directory that can be deployed anywhere.

### Deployment

Railway will automatically:
1. Run `npm install` to install Astro
2. Run `npm run build` to generate the static site in `dist/`
3. Start `npm start` which runs the static file server

## Project Structure

- `src/pages/` - Astro page components (each becomes a route)
- `src/layouts/` - Shared layout components
- `public/` - Static assets
- `dist/` - Built static site (generated by build process)
